# Contributing

Suggestions and corrections are welcome, especially:

- False-positive reports with the log line that caused them
- Real (anonymised) log samples for the SMTP, Active Directory and Sysmon rules
- Threat-intelligence references for any rule

Open an issue first for new rules. Follow the six steps in [`detection-rules/docs/methodology.md`](detection-rules/docs/methodology.md) and use an existing rule page as the template. Do not include real customer data, credentials or personal information in samples.
